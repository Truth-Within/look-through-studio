# PROJECT CONTEXT AND NON-NEGOTIABLE DECISIONS

Product name: The Look Through Studio. Channel name: The Look Through.

Core input: user-provided video containing speech. Core transformation: select meaningful portions of its ORIGINAL spoken audio, discard irrelevant ads/intros/digressions where editorially safe, organize coherent audio, then create entirely new cinematic illustrations and animations expressing that audio. The original source video visuals are not reused by default.

Visual identity: reference hand-drawn expressive stick-figure style as DEFAULT; AI may select other schematic cinematic illustration styles when topic warrants it, while preserving recognizable identity.

Creative objective: professional, visually captivating, polished, intelligent, accurate, high-end cinematic motion storytelling. Illustrations must express meaning and emotion, not simply keywords.

Optional per-production user-uploaded background music; automatic mixing and ducking. Modular multi-provider AI integrations; local/cloud/hybrid. YouTube OAuth connection and optional approved upload.

Required finished outputs: ONE main cinematic widescreen video AND AT LEAST FOUR fully produced cinematic vertical YouTube Shorts videos. Shorts are mandatory, not screenshots. Each Short must be edited as a self-contained mini-story with relevant illustrated animation and a clear hook, faithful original audio, captions, and music if supplied. Also deliver captions, metadata, audio, QC and edit provenance.

Development environment: favor Linux/Fedora compatibility, reproducible Python and Node setup, FFmpeg, affordable/free local tooling and optional API integration. Do not assume GPU capacity or paid provider access. Design CPU-capable fallback demo and declare performance limitations.

Do not build a separate scriptwriting documentary studio. This project transforms EXISTING AUDIO, not AI-written replacement narration. Do not add unrelated social automation features or mandatory complex approval stages. Editing review is required for potentially misleading cuts and publishing rights.
