# Look Through Studio — Android companion app

A native Android client for the studio web UI (`webapp.py`). Point it at the
computer that renders videos and you get full remote control from your phone:
start renders, watch the batch queue and live logs, play the main video and the
Shorts pack, read QC/metadata, download artifacts.

## Use

1. On the rendering computer, run the dashboard (binds `0.0.0.0`, prints its
   LAN addresses, and answers UDP discovery probes on port 8081):
   ```
   ./start_web.sh          # or: python3 webapp.py
   ```
   Phone and computer must be on the same Wi-Fi.
2. Install `LookThroughStudio.apk` (from `../dist/`, `../downloads/`, or
   `app/build/outputs/apk/release/app-release.apk`) on the phone.
3. Open the app → tap **Auto-discover** (finds the server via the UDP beacon,
   preferring an IP on the phone's own subnet) → **Save**. Or type the
   computer's **LAN address** manually (e.g. `192.168.1.70`, port `8080`) —
   **never `127.0.0.1`**: on the phone that is the phone itself. Then
   **Test connection** should show `✓ reachable`.
4. If the page can't load, the app shows an in-app error page with the URL it
   tried and the checklist (server running, same Wi-Fi, LAN IP not 127.0.0.1,
   firewall port 8080). In the phone's Chrome use `http://<computer-LAN-IP>:8080`.

## Build (offline, with the preinstalled toolchain)

```
cd android
gradle --offline :app:assembleRelease     # signed release APK
gradle --offline :app:assembleDebug       # debug APK (app id ...debug)
```

Uses AGP 8.11.0, Kotlin 1.9.22, compileSdk 36, minSdk 24, Java 17 — all from the
offline Maven cache, so `--offline` works. Icons are generated by
`python3 ../packaging/make_icons.py` (run it first if `res/mipmap-*` is missing).

## Code layout

- `MainActivity.kt` — full-screen WebView of the dashboard; same-host links stay
  in-app, external links open in the browser; fullscreen video via
  `WebChromeClient.onShowCustomView`; downloads open in the browser; toolbar menu:
  reload / server settings / open in browser / quit. `onReceivedError` on the main
  frame loads a friendly error page (with a `studio://settings` shortcut).
- `SettingsActivity.kt` — server host/port (SharedPreferences), shows the phone's
  own IP, **Auto-discover** (broadcasts `LOOKTHROUGH_DISCOVER` on UDP 8081 and
  parses the server's JSON beacon), and a **Test connection** button that GETs
  `/api/health`.
- No third-party dependencies (plain `android.app.Activity` + `WebView`), so the
  build needs nothing beyond the Android SDK + AGP + Kotlin plugin.

## Signing

`lookthrough.keystore` (password `lookthrough`, alias `studio`) is a local dev
key so release builds are installable. For Play Store publishing, generate your
own keystore and point `signingConfigs.release` in `app/build.gradle` at it.
